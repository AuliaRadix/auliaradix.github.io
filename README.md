## ⚡ Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/AuliaRadix/auliaradix.github.io.git
   cd auliaradix.github.io
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

4. **Build untuk static export (GitHub Pages):**
   ```bash
   npm run build
   ```
   Hasil static bundle siap deploy akan dihasilkan di folder `out/`.
